# 🎫 نظام تذاكر الدعم الفني | IT Helpdesk System

نظام متكامل لإدارة طلبات الدعم الفني داخل المنشآت الصغيرة والمتوسطة، مبني بلغة Python وواجهة عربية تدعم الاتجاه من اليمين لليسار.

يتيح للموظفين فتح تذاكر الأعطال، وللفنيين متابعتها ومعالجتها، وللإدارة قياس أداء الدعم الفني عبر مؤشرات دقيقة تشمل الالتزام باتفاقية مستوى الخدمة (SLA).

---

## ✨ المميزات

- **إدارة كاملة للتذاكر** — فتح، إسناد، تتبع حالة، وإغلاق.
- **نظام أولويات مرتبط بـ SLA** — لكل أولوية مدة محددة، والنظام يحسب الموعد النهائي ويرصد التجاوزات تلقائيًا.
- **خمس حالات للتذكرة** — جديدة، قيد المراجعة، قيد المعالجة، بانتظار المستخدم، مغلقة.
- **سجل إجراءات كامل** — كل حركة على التذكرة مسجّلة بالمستخدم والوقت والملاحظة.
- **صلاحيات حسب الدور** — موظف، فني دعم، مدير.
- **تقارير أداء** — متوسط وقت الاستجابة، متوسط وقت الإغلاق، نسبة الالتزام بالـ SLA، أداء كل فني، وأكثر الأعطال تكرارًا.
- **تصدير البيانات** — تقرير CSV جاهز للفتح في Excel بترميز عربي سليم.
- **قاعدة بيانات مزدوجة** — SQLite للتطوير المحلي، وPostgreSQL للإنتاج، بتبديل عبر متغير بيئة واحد.

## 🛠️ التقنيات المستخدمة

| المكوّن | التقنية |
|---|---|
| اللغة | Python 3.10+ |
| الواجهة | Streamlit |
| قاعدة البيانات | SQLite / PostgreSQL |
| معالجة البيانات | pandas |
| أمان كلمات المرور | PBKDF2-HMAC-SHA256 |

## 🚀 التشغيل المحلي

```bash
# 1) استنساخ المشروع
git clone https://github.com/USERNAME/helpdesk-system.git
cd helpdesk-system

# 2) إنشاء بيئة افتراضية
python -m venv .venv
.venv\Scripts\activate        # على Windows
# source .venv/bin/activate   # على macOS / Linux

# 3) تثبيت المتطلبات
pip install -r requirements.txt

# 4) تعبئة بيانات تجريبية (اختياري لكن مُوصى به)
python -m database.seed

# 5) تشغيل التطبيق
streamlit run app.py
```

سيفتح التطبيق على `http://localhost:8501`.

## ☁️ التشغيل على PostgreSQL

أنشئ ملف `.env` أو اضبط متغير البيئة:

```
DATABASE_URL=postgresql://user:password@host/dbname?sslmode=require
```

عند وجود هذا المتغير ينتقل النظام تلقائيًا إلى PostgreSQL ويستخدم مخطط `database/schema_postgres.sql`.

## 📁 هيكل المشروع

```
helpdesk-system/
├── app.py                      # نقطة التشغيل والتنقل بين الصفحات
├── database/
│   ├── connection.py           # طبقة الاتصال (SQLite / PostgreSQL)
│   ├── schema.sql              # مخطط SQLite
│   ├── schema_postgres.sql     # مخطط PostgreSQL
│   └── seed.py                 # بيانات تجريبية
├── models/
│   ├── user.py                 # المستخدمون والمصادقة
│   ├── ticket.py               # التذاكر وانتقالات الحالة
│   └── action_log.py           # سجل الإجراءات
├── views/
│   ├── login.py                # تسجيل الدخول
│   ├── dashboard.py            # لوحة المؤشرات
│   ├── ticket_form.py          # فتح تذكرة
│   ├── tickets_list.py         # القائمة والتفاصيل
│   ├── reports.py              # تقارير الأداء
│   └── admin.py                # إدارة المستخدمين
├── utils/
│   ├── auth.py                 # تشفير كلمات المرور
│   ├── sla.py                  # قواعد SLA والمسميات
│   └── styles.py               # تنسيق RTL
└── requirements.txt
```
